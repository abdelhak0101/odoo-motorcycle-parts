# Motorcycle Parts Shop — Odoo 17

A custom Odoo 17 application for managing a motorcycle parts business.

## Overview

This project was developed to manage core business operations for a motorcycle parts shop, including products, customers, orders, inventory, payments, and reporting.

The application was developed as a custom Odoo module using Python, Odoo ORM, XML, and PostgreSQL.

## Features

* Motorcycle parts product management
* Customer management
* Customer types and financial information
* Sales/order management
* Order workflow
* Inventory and stock management
* Barcode support
* Custom business logic
* Access rights and security rules
* Custom PDF reports
* Customer ID card report
* Product barcode/card report
* Order reports
* Custom Odoo menus, views, and actions

## Installation

1. Install Odoo 17.
2. Copy the `mgc_motorcycle_parts` module into your custom addons directory.
3. Restart Odoo.
4. Update the Apps list.
5. Install **Motorcycle Parts Shop**.
